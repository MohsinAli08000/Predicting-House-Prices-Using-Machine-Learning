# 🏡 Predicting House Prices Using Machine Learning

This project demonstrates how to build machine learning models to **predict house prices** based on various features such as size, location, condition, number of bedrooms/bathrooms, and more.

## 📌 Key Features:
- End-to-end ML pipeline: data cleaning, preprocessing, modeling, and evaluation
- Visual EDA using Seaborn and Matplotlib
- Feature encoding and scaling
- Models used: **Linear Regression** & **Random Forest Regressor**
- Performance evaluation using **MAE**, **RMSE**, and **R² Score**

## 📂 Dataset:
The dataset includes information about residential properties, such as:
- Area (sqft)
- Bedrooms, bathrooms
- Floors, condition, waterfront
- Price (target variable)

## ⚙️ Tools & Libraries:
- Python, Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn

## 🚀 Goal:
To showcase how machine learning can be applied to real-world data for **accurate price prediction in the housing market**.
